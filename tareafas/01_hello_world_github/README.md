# Tarefa 01 — Hello World GitHub

Sua primeira tarefa não tem código. O objetivo é aprender o fluxo que usaremos em todas as entregas: criar uma branch, editar um arquivo e abrir um Pull Request.

---

## O que fazer

Todo repositório tem um `README.md` que explica o projeto. Nesta tarefa, **você é o projeto**.

Crie um arquivo `README.md` como se fosse o README de um repositório chamado `seu-nome`. Seu arquivo deve ter:

- Seu nome como título (`# seu-nome`)
- Uma seção `## Sobre o projeto` — quem é você em poucas linhas
- Uma seção `## Tecnologias` — uma lista com suas habilidades e ferramentas (pode ser culinária, esporte, idiomas — não precisa ser só tech)
- Uma tabela `## Status` com 3 coisas que você domina, 3 que está aprendendo e 1 que quer aprender
- Uma seção `## Como me chamar` — nome, curso, forma de contato preferida
- Um `## Aviso importante` com uma citação ou frase que representa você

Consulte `recursos/guia-markdown.md` se tiver dúvida sobre a sintaxe.

---

## Como entregar

1. Crie sua branch: `tarefa-01/seu-nome`
2. Crie o arquivo em: `tarefas/01-hello-world-github/entregas/seu-nome/README.md`
3. Faça o commit: `tarefa-01: apresentacao seu-nome`
4. Abra o Pull Request no GitHub

Dúvidas sobre o fluxo? Consulte `recursos/tutorial-vscode.md`.
