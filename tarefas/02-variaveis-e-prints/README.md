# Tarefa 02 — Variáveis, Operações e Prints

Nesta tarefa você vai escrever seus primeiros programas em Python. O notebook tem duas partes independentes — faça as duas.

---

## O que você vai praticar

- Declarar variáveis
- Realizar operações aritméticas
- Exibir resultados com `print()`
- Formatar saída com f-strings

---

## Como entregar

1. Crie sua branch: `tarefa-02/seu-nome`
2. Abra o notebook em: `tarefas/02-variaveis-e-prints/entregas/seu-nome/notebook.ipynb`
3. Complete as células indicadas com `# SEU CÓDIGO AQUI`
4. Salve e faça o commit: `tarefa-02: resolução seu-nome`
5. Abra o Pull Request no GitHub
